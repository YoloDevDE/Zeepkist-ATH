# Current Prompt

Drop a `.txt` file in here to brief the next piece of work. The file is the brief — it can hold layouts, formats and
examples that would be awkward to type into a chat box.

Once it has been worked off it moves to `../RecentPrompt/` with a timestamp, e.g. `2026-07-31_2038_UI.txt`.

This README only exists so the folder survives a clone; git does not track empty directories.
